First start on Windows now works without waiting; the Halo blends into the window.

## New
- **Ready-to-go resolver (Windows):** Python and the required packages now ship with the installer. No downloads on first start; Home and search work right away.
- **Halo blends into the window:** The glow on the home page now spills softly under the sidebar and the top bar instead of being cut off at the edge.
- **Sidebar dimming:** Choose Clear, Half or Dark for the sidebar under Appearance → Background glow.
- **Live spectrum (Windows):** The spectrum on the Profile page and "React to music" now work on Windows too.
- **Log files:** Settings → Sources & About → "Open logs". You can attach these files when reporting a problem.

## Fixes
- **Not starting on Windows:** On some computers Vynz failed to start with "VCRUNTIME140.dll was not found". Fixed.
- **"Resolver closed" error:** If the first-run setup stalled on a slow connection, the resolver never started and Home didn't load. Downloads are now more robust and retried.
- **Colored halo on gray covers:** Black-and-white covers got a halo in a color they don't have (e.g. blue). It now stays in the cover's tone.
- **Grain:** Off by default on new installs.
